서버 전달용 GAN 추가 학습 패키지 - 2026-10-22

Git 공유/가중치 별도 설치와 최종 실행 안내는 README.md를 먼저 읽으세요.
검토 범위와 확인하지 못한 부분은 검토결과.txt 및 validation/에 있습니다.

실행 파일
01_GAN_부분가리기.ipynb: 부분 가리기만 사용하는 기준 버전.
02_GAN_부분전체혼합.ipynb: 부분80%/전체20%가 기본인 혼합 버전. 비율 수정 가능.
둘 중 하나를 열면 해당 설정의 학습 하나만 실행한다. 서로를 자동 실행하지 않는다.
공통 .py, data, weights 폴더를 같은 위치에 유지한다. 노트북만 따로 보내면 실행되지 않는다.

서버 담당자가 할 일
1. ZIP을 풀고 GPU에 맞는 torch/torchvision과 Jupyter 커널을 준비한다.
   설치 안내: https://pytorch.org/get-started/locally/
   코드는 torch2.4 이상 API를 쓰며, 검증 환경은 별도 검증 JSON에 기록한다.
   노트북은 보조 numpy/scipy/Pillow만 설치하고 torch를 자동 교체하지 않는다.
2. 원하는 노트북에서 DATA_ROOT, GPU_INDEX, BATCH_SIZE, 원본 수와 학습량을 설정한다.
3. Train 데이터가 없으면 약4GB 공식 ZIP을 다운로드한다. 압축해제/체크포인트까지 여유20GB 권장.
   이미 Train/Urban 및 Train/Rural이 있으면 그 상위 폴더를 DATA_ROOT로 지정한다.
4. 가림 미리보기와 class_distribution.json을 확인하고 나머지 셀을 실행한다.
5. 생성 결과와 human_review.csv를 검토한 뒤 RUN_NAME_results.zip을 돌려준다.

이미 완료한 학습 / 새로운 학습의 구분
기준 semantic_04000은 작은 U-Net 생성기와 PatchGAN을 LoveDA로 처음부터 학습한 계보이다.
256개 원본→1,024 고정패치로 확대한 복원 기준에서 지도 주입5단계와 교사 의미 손실 등을 추가해4,000회 반복했다.
그 단계의 실제 G 업데이트3,999회, D4,000회였다. 원래 지도/원본 RGB만 학습했다.
현재 코드는 그 저장 모델을 엄격히 로드하여 새 Adam으로 추가 학습한다. 과거 전체 학습의 비트 단위 재현 코드는 아니다.
당시 입력·실제 학습 로그는 data/historical_training_*.json, 목적·성과는 상위 보고서에 있다.
사진 전체 가리기는 새 GAN 가설이며 아직 편집 품질 개선을 확인한 결과가 없다.

학습 설정과 보정
- NUM_TRAIN_IMAGES:2..2490 또는 None. 기존 holdout32장은 항상 제외한다.
- PATCH_SIZE: native256 또는512. 기존256 확대가 아니라 원본에서 해당 크기를 자른다. 기본256.
- PATCHES_PER_IMAGE: 계획 주기당 원본별 후보crop 수. 다음 주기에는 새로운 crop을 만든다.
- FULL_IMAGE_RATIO: 선택한 패치의 RGB를 전부 가리는 draw 비율. 지도와 실제 정답 RGB는 유지한다.
- 클래스 보정: 모드별 실제 가림 픽셀을 정규화한 분포를 집계해 부족한 클래스를 소프트 보정한다.
  자연 후보 분포와 사용 가능한 클래스 균등 분포를 BALANCE_STRENGTH로 섞는다. 물리적으로 정확한 균등을 보장하지 않는다.
  초반 한 번은 모든 선택 원본을 노출한다. 이후 클래스 보정으로 crop/원본 노출 횟수는 달라질 수 있다.
  targets/실제면적/32픽셀 이상 가림횟수를 plan.json 및 class_distribution.json에 남긴다.
- 손실은 기존 의미 강화 구성을 유지한다. void0은 유효영역 손실에서 제외한다.
  교사 신뢰도 조건으로 실제 CE가 적용되는 클래스별 픽셀 수도 기록한다. 픽셀 수가 같아도 기울기 영향이 같은 것은 아니다.
- 두 버전의 원본 집합과 정책/seed를 같게 할 수 있지만 가림 방식에 따라 균형 선택 crop이 달라질 수 있다.
  이것은 가리기+균형 샘플링 정책 비교이며 완전히 동일한 미니배치의 단일 요소 인과실험이라고 부르지 않는다.
- 기존 모델은 모든 원본256장을 이미 본 상태다. 이번 선택에서 제외됐다고 새 최종 테스트가 되는 것은 아니다.

시드와 학습 예산
SEED=None이면 실제 seed를 새로 생성하여 저장한다. 같은 RUN_NAME에서는 기록된 seed를 재사용한다.
데이터/마스크 계획을 고정해 저장하며 모델 초기화에도 실제 seed를 사용한다.
현재 GAN은 노이즈입력/Dropout이 없어 생성은 결정적이다. 생성 seed로 다양한 출력이 나오지 않는다.
TOTAL_UPDATES는 반복 예산이다. AMP skip이 있으면 실제 G/D optimizer 업데이트 수가 작아질 수 있어 따로 기록한다.
서로 다른 GPU/라이브러리 또는 재개 학습의 비트 단위 동일성은 보장하지 않는다.

저장·재개
latest.pt는 G/D,optimizer,scaler,RNG,진행상태를 담는다. 이전 유효 파일 previous도 남긴다.
진행 중 RUN_DIR/STOP 파일을 만들면 현재 배치를 마친 뒤 저장한다.
재개 전 STOP을 확인 후 삭제하고 같은 설정/코드/데이터로 RESUME=True를 쓴다.
강제 종료는 마지막 주기 저장 이후 진행을 잃을 수 있다. checkpoint가 있는데 다른 설정이면 새 RUN_NAME을 써야 한다.
학습 잠금 파일은 동시 실행을 막는다. 서버 강제 종료 후에는 해당 PID가 종료됐는지 확인한 뒤 stale lock을 직접 정리한다.
완료한 실험은 자동 재학습하지 않는다.

평가
고정 개발51사례(기존35 + Val16)는 모두 개발에 재사용된 자료다.
원래 지도/편집 지도/지도 제거 출력과 실제 원본을 나란히 저장한다.
MAE는 원래 지도 복원, map_change는 지도 반응량, audit 목표 픽셀 비율은 보조 지표이며 실제 편집 성공률이 아니다.
실제 원본의 분할기 라벨 일치도도 기록한다. 학습 교사와 독립 가중치의 audit을 사용하지만 구조/학습 데이터는 공유한다.
human_review.csv의 객체·경계·질감 판정을 사람이 작성한다. 재평가해도 기존 수동 판정은 지우지 않는다.
선택적 whole-frame probe는 외부 RGB를 보존하지 않는 지도 생성 진단이며 실제 국소 편집 성능과 구분한다.
미사용Val1,107 원본 풀은 별도 파일에 예약돼 있다. 기본 꺼진 최종 테스트 셀에서 Val 데이터를 주면 라벨 기하로 사례를 고정한다.
최종 테스트 결과를 보며 모델을 선택하면 개발 평가로 취급해야 한다. 원본 분리는 지리적 독립성을 보장하지 않는다.

검증 범위
패키지의 검증 JSON을 확인한다. 작은 forward/backward/저장·재개 점검과 과거 출력 재현은 품질 개선의 검증이 아니다.
새4000회 본학습은 이 PC에서 실행하지 않는다. 기존 중단 v11도 재개하지 않는다.
