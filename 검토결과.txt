서버 전달용 코드 검토 결과 — 2026-10-22

결론: 두 노트북과 공통 코드를 공유 가능한 형태로 구성했다. 본학습과 성능 개선 실험은 실행하지 않았다.
이전에 실시한 1~3회 점검은 임시 모델을 이용한 기능 확인이며 학습 성과가 아니다.

완료한 점검
- 노트북 두 개를 실제 Jupyter 커널에서 각각 3회 반복 설정으로 실행: 저장·평가51건·결과ZIP까지 완료.
- CPU/CUDA 임시 모델에서 부분/전체 가림, backward, 저장·재개 확인. 같은 환경에서 재개 전후 결과 일치.
- 기존 모델 구조 strict 로딩, 원래 가중치 미변경, 학습 입력/출력 크기와 유한값 확인.
- 자동 시드 기록·재사용, 설정이 바뀐 재개 거부, 평가 영역 밖 픽셀 보존 확인.
- 512 패치 forward 확인. 실제 512 학습과 품질은 미검증.
- 최종 테스트 구성 경로는 인공 데이터로만 검사. 예약한 실제 Val 최종 테스트는 사용하지 않음.

검토하며 수정한 문제
- 노트북 코드 셀 들여쓰기 오류 수정.
- 짧은 CUDA 점검에서 과도한 초기 AMP scale로 생성기 업데이트가 누락되던 문제: 초기값128로 낮추고 실제 업데이트·skip 기록 추가. 수정 후 G/D 각3회 업데이트 확인.
- 데이터 메타데이터의 평가 원본 제외 키 불일치 수정.
- 선택 GPU 사용 가능 여부를 다운로드 전에 검사.
- 가중치 누락 시 설치 명령 안내, 별도 가중치ZIP의 SHA256 검사 후 설치.
- 기준 모델 평가에서 audit 사용/미사용 출력 폴더 분리.
- 평가 비교 시 사례 이름뿐 아니라 실제 RGB·지도·마스크 지문 일치 검사.
- 실행 결과·가중치·원본 데이터·캐시를 Git에서 제외.

최종 배포 검사
코드ZIP을 새 폴더에 풀어 가중치 설치 및 SHA256/초기 forward 검사,
전체 Python/노트북 셀 구문 검사, Git 포함/제외 규칙, 평가·비교 보호 동작을 별도로 확인한다.
상세 결과는 validation/git_delivery_validation.json에 기록한다.
위의 이전 실행 점검 후 변경된 배포/초기검사/평가 보호 코드는 학습 없이 검사한다.

아직 확인하지 않은 범위
- 조원이 사용할 Linux 배포판·GPU·CUDA·torch 조합의 실제 실행.
- 4000회 본학습의 수렴/자연스러움/편집 품질 개선. 전체 가리기20%가 최적이라는 근거는 아직 없음.
- 공식4GB ZIP을 처음부터 새로 내려받는 전 과정과 서버 네트워크·디스크 환경.
- 512 패치 backward와 최대 GPU 메모리, 실제 예약 Val 최종 평가.

주의할 해석
가림 클래스 균형은 근사 보정이다. 동일 seed라도 두 방식의 crop 선택은 달라질 수 있다.
평가 점수는 지도 반응과 분할기 보조 지표이며 편집 성공률은 아니다.
원래 v11 중단 상태는 유지했고 재개하지 않았다.
